# Alloy Smelter

### Required fields

- `"energy"` Energy consumed every tick when the recipe is present
- `"ticks"` Duration of the recipe
- `"left"`
- `"right"`
- `"output"`

```js
{
  "type": "synergy:machine/alloy_smelter",
  "energy": <integer>,
  "left": <item-sized-ingredient>,
  "output": <item-stack>,
  "right": <item-sized-ingredient>,
  "ticks": <integer>
}
```
