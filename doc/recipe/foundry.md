# Foundry

### Note:
- `"ticks"` can change based on [Foundry Fuels](https://github.com/DevDyna/Synergy/blob/21.1/doc/recipe/foundry_fuels.md) and percentuage of molten fluid inside the foundry (configurable)

### Required fields

- `"ticks"` Duration of the recipe
- `"fluid"`
- `"input"`

```js
{
  "type": "synergy:foundry",
  "fluid": <fluid-stack>,
  "input": <item-ingredient>,
  "ticks": <integer>
}
```
