# Electric Furnace

### Required fields

- `"energy"` Energy consumed every tick when the recipe is present
- `"ticks"` Duration of the recipe
- `"input"`
- `"output"`

```js
{
  "type": "synergy:machine/electric_furnace",
  "energy": <integer>,
  "input": <item-sized-ingredient>,
  "output": <item-stack>,
  "ticks": <integer>
}
```
