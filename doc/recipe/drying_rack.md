# Drying Rack

### Note:
- `"ticks"` can decrease and increase based on specific conditions!

### Required fields

- `"ticks"` Duration of the recipe and can change based on item stack size configurable via config
- `"input"`
- `"output"`

```js
{
  "type": "synergy:drying_rack",
  "input": <item-ingredient>,
  "output": <item-stack>,
  "ticks": <integer>
}
```
