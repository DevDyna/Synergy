# Electric Melter

### Required fields

- `"energy"` Energy consumed every tick when the recipe is present
- `"ticks"` Duration of the recipe
- `"fluid"`
- `"input"`

```js
{
  "type": "synergy:machine/electric_melter",
  "energy": <integer>,
  "fluid": <fluid-stack>,
  "input": <item-sized-ingredient>,
  "ticks": <integer>
}
```
