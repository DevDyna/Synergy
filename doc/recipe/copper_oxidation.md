# Copper Oxidation

### Note:
- `"step"` It doesn't change nothing if added another one of same type!
- This recipe type cannot be customized but can be removed on recipe viewers

### Required fields

- `"step"`
- `"catalyst"` Define what will show as item used to convert blocks

```js
{
  "type": "synergy:copper_oxidation",
  "step": <hardcoded>,
  "catalyst":<item-ingredient>
}
```
