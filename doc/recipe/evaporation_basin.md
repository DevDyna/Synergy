# Evaporation Basin

### Note:
- `"ticks"` can be speed-up placing specific blocks below the block

### Required fields

- `"ticks"` Duration of the recipe
- `"fluid"`
- `"output"`


```js
{
  "type": "synergy:evaporation_basin",
  "fluid": <fluid-sized-ingredient>,
  "output": <item-stack>,
  "ticks": <integer>
}
```
