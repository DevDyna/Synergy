All possible in-game documentation that this project support

- Default Tooltips

### Mod Compat

- [JEI](https://legacy.curseforge.com/minecraft/mc-mods/jei)
  All of recipes support JEI with multiple useful informations

- [Jade](https://legacy.curseforge.com/minecraft/mc-mods/jade)
  There are many jade custom-plugins to show useful informations

- [Guideme](https://legacy.curseforge.com/minecraft/mc-mods/guideme)
